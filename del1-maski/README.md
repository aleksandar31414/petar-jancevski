# ВрвТура – организатор на планинарски тури

Веб програмирање 2026 · **Дел 1: нацрт на апликација и модел на рамка**

ВрвТура е апликација за планинарски клуб. Клубот објавува организирани тури, корисниците се пријавуваат на нив и оставаат коментари и оцени. За секоја тура апликацијата прикажува временска прогноза за конкретниот врв и денот на турата, преземена од надворешниот извор **Open-Meteo API**.

## Како да се отвори
Отворете ја `index.html` во прелистувач. Сите маски се статички HTML страници со фиксни податоци. Стиловите (Bootstrap 5.3, Bootstrap Icons, Chart.js) се вчитуваат од CDN, па е потребна интернет врска.

## Маски на екрани
| Датотека | Екран | Барање |
|---|---|---|
| `najava.html` | Најава / Регистрација | најава/регистрација |
| `dodaj-tura.html` | Додај тура | додавање елемент |
| `ture.html` | Сите тури | printout на листа |
| `tura-detali.html` | Детали за тура | детален пример, зумирање, коментари, popup |
| `brisi-tura.html` | Избриши тура | бришење елемент |
| `uredi-tura.html` | Уреди тура | прегледување и уредување, историја на измени |
| `prebaruvanje.html` | Пребарување | пребарување |
| `prognoza.html` | Прогноза | интеграција со надворешен извор (Open-Meteo) |
| `index.html` | Почетна | root страница `/` |
| `profil.html` | Мој профил | drag & drop, историски преглед |
| `admin.html` | Админ табла | графикони, управување со корисници |
| `izvestaj.html` | Извештај | генерирање извештаи |

Секоја маска на дното има дел „Опис на функционалностите на овој екран“.

## Кориснички улоги
- **Гостин**: ги гледа турите, деталите, пребарувањето и прогнозата.
- **Регистриран корисник**: сè што може гостинот, плус пријава на тура, коментари и оцени, личен профил и листа за опрема. Ги менува само своите податоци.
- **Администратор / водич**: целосен пристап до турите, корисниците, извештаите и `/db`.

## Планирани колекции (MongoDB)
Корисници, Локации, Тури (зависи од Локации и Корисници), Пријави (зависи од Корисници и Тури), Коментари (зависи од Корисници и Тури), Опрема, Активности.

## Надворешен извор
[Open-Meteo](https://open-meteo.com/) – бесплатен API без клуч. Базата ги чува само координатите на врвовите, а прогнозата (температура, ветер, врнежи) се презема во живо.

## Планирани npm пакети
`bcryptjs`, `nodemailer`, `jsonwebtoken`, `pdfkit`, `swagger-jsdoc`, `swagger-ui-express`.
