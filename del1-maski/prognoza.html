Како работи интеграцијата

Апликацијата ги чува само координатите и надморската височина на врвовите (колекција Локации). Прогнозата се презема во живо од бесплатниот Open-Meteo API (без API клуч) – податоци кои базата на проектот не ги содржи. Пример барање и (скратен) одговор:

GET https://api.open-meteo.com/v1/forecast?latitude=41.00&longitude=21.23&elevation=2601 &daily=temperature_2m_max,temperature_2m_min,precipitation_probability_max,wind_speed_10m_max &current=temperature_2m,wind_speed_10m&timezone=Europe/Skopje { "current": { "temperature_2m": 4.1, "wind_speed_10m": 22.0 }, "daily": { "time": ["2026-11-14"], "temperature_2m_max": [6.2], "temperature_2m_min": [-1.0], "precipitation_probability_max": [10], "wind_speed_10m_max": [18.4] } }
Опис на функционалностите на овој екран
  • Интеграција со надворешен извор: временска прогноза од Open-Meteo API за координатите и височината на врвот.
  • Избор на врв или конкретна тура; копче за освежување на прогнозата.
  • Моментални услови (температура, чувство, ветер, влажност, видливост, изгрев/зајдисонце) и прогноза за 7 дена; денот на турата е означен.
  • Автоматска проценка дали условите се поволни, со известување по е-пошта до водичот при лоша прогноза.
  • Податоците од API не се чуваат во базата – ја збогатуваат апликацијата со информации кои базата ги нема.
  • Во Дел 4 ова е посебен Angular/React сервис за надворешната услуга.
